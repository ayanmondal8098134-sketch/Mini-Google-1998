ℹ️ How the 100,000 Random Surfer (Dice Throw) simulation works

The Problem: Pre-1998 search engines counted word repetition. Spam sites like pizza-pizza-pizza.com easily manipulated search results by keyword stuffing (ranking #1).

Larry Page & Sergey Brin's Breakthrough (PageRank): A virtual web surfer starts on a random page. At each step, a random die is rolled:

  • 85% of the time (damping factor d = 0.85): The surfer randomly clicks one of the outbound links on the current page.
  • 15% of the time (teleportation): The surfer gets bored and jumps to any random webpage across the internet.

After 100,000 dice throws, the fraction of visits each page receives represents its authority. Because Pune's food guides link to best-pizza-pune.com, it legitimately takes the #1 spot!
